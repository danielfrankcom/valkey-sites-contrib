Cross-site search demo for the Valkey sites

The four Valkey sites below are built from their upstream repositories with a proposed change applied: each site keeps its own Pagefind search index, and its search box also searches the other three sites. This is an unofficial demo, not the real sites.

  • valkey.io (Zola). The search box here is Pagefind's default UI, as a placeholder.
  • GLIDE docs (Starlight)
  • Valkey Admin docs (Starlight)
  • Spring Data Valkey docs (Starlight)

The proposed changes, how the demo is built, and what it doesn't show are in danielfrankcom/valkey-sites-contrib.
